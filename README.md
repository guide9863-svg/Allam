# Allam 기상알람 ⏰

아침에 못 일어나는 사람을 위한 **엄청 시끄러운** 안드로이드 알람 앱.
교대 근무(24시간 격일제, 2교대 등) 패턴에 맞춰 반복되고, **휴대폰을 들고 실제로 움직여야만** 꺼집니다.

## 설치 (휴대폰)

1. 휴대폰 브라우저로 이 저장소의 **Releases** 페이지를 엽니다
   (`https://github.com/guide9863-svg/Allam/releases/latest`).
2. `Allam-1.0.N.apk` 를 내려받아 설치합니다 ("출처를 알 수 없는 앱" 허용 필요).
3. 앱 실행 → **설정 탭**에서 모든 권한이 ✓ 인지 확인합니다.
4. **교대표 탭**에서 근무 패턴과 오늘 근무를 맞추고, **알람 탭**에서 알람을 추가합니다.
5. 설정 탭의 **"10초 뒤 테스트 알람"** 으로 화면을 끈 상태에서 꼭 한 번 시험해 보세요.

> Android 8.0(API 26) 이상. 코드를 푸시하면 GitHub Actions(클라우드)가 APK를 빌드해 Release 로 올립니다.

## 기능

### 기본 알람
- 시간·이름·켜기/끄기, 한 번 / 요일 반복 / **교대 근무 연동** 반복
- 다음 1회 건너뛰기, 스누즈(횟수·간격 설정), 10초 뒤 미리 울려보기
- 재부팅·시간대 변경·앱 업데이트 후 자동 재등록 (잠금 해제 전에도 동작)
- 기상 기록 (몇 분 만에, 몇 걸음, 다시 울린 횟수)

### 교대 근무
- 프리셋: 격일제(당번·비번), 당·비·휴, 당·비·비, 주·야·비·휴, 주·주·야·야·비·비, 주·주·야·야·비·비·휴·휴
- 직접 패턴 만들기, 근무 종류 추가(이름·색)
- "오늘이 몇 번째 날인지"만 누르면 전체 일정이 맞춰짐
- 달력에서 날짜를 눌러 **근무 교환/변경** (그 날만 다른 근무로)
- 알람은 "당번 날 07:00", "야간 날 16:00" 처럼 근무 종류별로 설정

### 시끄러움
- 알람 스트림으로 재생 → 무음/진동 모드에서도 울림
- 알람 볼륨 **최대 고정** (울리는 중 볼륨을 내려도 다시 최대로), 볼륨 버튼 무시
- 내장 합성음: 초강력 사이렌 / 3.1kHz 화재경보 비상벨 / 불협화음 (또는 휴대폰 알람음)
- 강한 진동, 카메라 플래시 깜빡임, 빨갛게 번쩍이는 화면

### 움직여야 꺼지는 기상 확인
```
울림 ──[소리 끄고 움직이기]──▶ 조용 (센서 감시)
  ▲                                │
  └──── N초 동안 움직임 없음 ◀─────┘   (반복)

울림/조용 ──[걸음 목표 또는 연속 움직임 목표 달성]──▶ 기상 완료 (더 이상 안 울림)
```
- **걸음**: 걸음 감지 센서(없으면 가속도계로 추정)
- **연속 움직임**: 1초 단위 가속도(중력 제거) RMS 또는 자이로 각속도 RMS 가 문턱값 이상
- 울리는 동안에는 알람 진동·스피커 떨림을 움직임으로 오인하지 않도록 걸음 센서만 인정,
  "소리 끄고 움직이기" 후에는 가속도·자이로 움직임도 인정
- 움직이다 멈추면 진행도 0으로 초기화 → 침대에서 뒤척여서 끄기 불가
- 손으로 흔든 가속도 봉우리(자이로 회전이 큰 것)는 걸음으로 세지 않음
- 울리는 중 전원 재시작·앱 종료로 끄려 해도 감시 알람이 1~2분 안에 다시 울림 (잠금 해제 전에도)
- 꺼져 있던 동안 놓친 알람(30분 이내)은 켜지자마자 울림
- 엄격 모드: "걸음만 인정" (흔들기로는 안 꺼짐)
- GPS 는 실내 오차(5~20m)가 커서 쓰지 않음 — 걸음으로 자리 이동을 확인
- 안전장치: 60분 동안 기상 미확인 시 멈추고 알림, 긴급 해제(계산 문제 3개)

## 구조

```
core/   순수 Kotlin 로직 (JUnit 테스트)
  ShiftSchedule     교대 패턴, 근무 변경, 프리셋
  AlarmCalculator   다음 울림 시각 계산 (교대/요일/한 번, 건너뛰기)
  MotionAnalyzer    센서 값 → 걸음 수, 연속 움직임 초, 정지 시간
  WakeController    울림 → 조용 → 다시 울림 → 기상 상태 기계
  ToneSynth         알람음 PCM 합성
app/    안드로이드 앱 (Jetpack Compose)
  alarm/AlarmScheduler  AlarmManager.setAlarmClock 등록
  alarm/AlarmService    울림 포그라운드 서비스 (소리·진동·플래시·센서)
  ui/RingActivity       잠금화면 위 알람 화면
```

로컬 빌드: `./gradlew :core:test :app:assembleRelease` (Android SDK 필요)

서명 키 `app/allam-sideload.jks` 는 개인 사이드로드용으로 저장소에 포함되어 있어
어디서 빌드하든 같은 서명이 되어 재설치 없이 업데이트됩니다.
